# dashboard-kit

Agent skills for building honest, readable data dashboards (Hermes / Scout / any SKILL.md agent).

Build: uxui, shadcn-ui, dash-cog
Layout and clarity: operator-dashboard-information-hierarchy, operator-dashboard-legibility, attention-first-operator-ui
Correct numbers: derived-count-and-tier-integrity, paged-list-count-integrity, empty-view-debugging
Proof: ui-visual-verification
Data: powerbi-semantic-model-extraction, xlsx

Install: copy each folder into your agent's skills directory (for Hermes: ~/.hermes/skills/).

For video, motion graphics and data stories, see https://github.com/idanshimon/creator-kit
