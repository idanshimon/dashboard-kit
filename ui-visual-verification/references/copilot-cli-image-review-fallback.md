# Independent image review through Copilot CLI

When the configured vision_analyze model is rejected, do not claim screenshots inspected. An available, verified image-capable Copilot CLI model can supply actual independent visual critique, with explicit image attachments and saved usage metadata.

- Attach real PNGs with `--attachment <path>`; request specific defect hunting rather than praise. Plain `.txt` files are rejected by the CLI attachment flag (images/native documents only); put extracted review text directly in the prompt and attach only supported assets. State exact capture origin, viewport and whether before/after fault, local candidate or public production. Images alone do not prove test counts, commit hashes, deployment or recovery.
- Select a model returned by the current provider catalog; verify `currentModel` and actual request metrics in `--usage-output-file`. If high reasoning is requested, record the request separately from any returned reasoning-token evidence. Preserve the actual critique and usage, not a fabricated summary.
- For a review-only process, restrict available tools to view/read and deny shell/write, disable unrelated MCP tools, no remote execution/export and no custom instructions. This is a CLI permission envelope, not independently proven OS sandboxing. Do not call a read-capable process tool-free.
- After a critical review, reproduce reported UI defects with real rendered DOM geometry/computed styles before patching. Inspect opacity after transitions settle; immediate reads can misleadingly show opacity 1 before later dimming to 0.13.
- Full-page screenshots can repeat sticky/viewport sections or show a fixed sidebar ending at the viewport boundary. Count actual DOM headings and exercise real mobile controls before diagnosing duplicate UI. Capture viewport-sized mobile states, scroll to actual editable rows, and inspect the resulting pixels. A no-horizontal-overflow assertion is not proof mobile editing works.
- For Archify presenter wrappers, the fixed toolbar can collide with the always-visible explanation panel. Reserve the actual panel width through an app-owned reproducible adapter, preserve renderer provenance, assert non-overlapping bounding boxes and readable node opacity, and label decorative motion Animation rather than Live telemetry.
- Re-review corrected desktop, mobile checklist and every graph chapter. Resolve or explicitly retain nonblocking defects; a passing thin-slice review is not full foundation qualification, human approval or hosted enforcement.
